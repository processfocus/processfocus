---
title: Organisation settings
description: Configure the properties of the root Organisation construct.
---

Organisation settings include:

- **Display Name** - How the organisation appears in the UI
- **Timezone** - Default timezone for dates and scheduling
- **Default Language** - Language for generated forms and notifications
- **Security Policies** - Password requirements, session timeouts
- **Branding** - Custom colors and logos (Enterprise plans)

## Example

Set organisation-wide properties when you create the `Organisation`:

```typescript
import { Organisation } from "@pf/process"

export const org = new Organisation({
  name: "Demo Company",
  acronym: "Demo",
  timeZone: "Pacific/Auckland",
  locale: "en-NZ",
})
```

The time zone determines how times are displayed to users. It's the
timezone your business operates in.

| Property | Description |
| --- | --- |
| `name` | Full name of the organisation. Required. |
| `acronym` | Optional shortened name. |
| `timeZone` | IANA time zone identifier. Defaults to `UTC`. |
| `locale` | BCP 47 locale for organisation-authored date and time displays. Defaults to `en`. |
| `businessCalendar` | Optional working hours, holidays, and special periods. If omitted, the calendar is open 24/7. |

## Business Calendar

Many concepts in Process Focus are in business hours. For example if
there is an SLA of 8 hours, this is always understood in the terms of
8 business hours. So if the working hours are from 9am to 5pm, and an
order comes in at 4pm, and the SLA is to ship in 8 hours, the system
will not expect this to be shipped by midnight, but by 4pm the next day.

This is the same for holiday periods, business days, they all get
taking into account for scheduling and SLA purposes.

Set `businessCalendar` to define which hours count when a process measures
time in business hours. This example uses Monday to Friday, 09:00 to 17:00
in Auckland, and closes on 25 December each year.

```typescript
import { createDefaultConfig, fixedHoliday } from "@pf/business-calendar"
import { Organisation } from "@pf/process"

const timeZone = "Pacific/Auckland"

export const org = new Organisation({
  name: "Demo Company",
  timeZone,
  businessCalendar: {
    ...createDefaultConfig([fixedHoliday("Christmas Day", 12, 25)]),
    timezone: timeZone,
  },
})
```

With this calendar, a deadline two business hours after 16:00 on an ordinary
Friday falls at 10:00 the following Monday, provided Monday is not a holiday.
