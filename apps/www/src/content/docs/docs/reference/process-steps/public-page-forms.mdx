---
title: Public page forms
description: Forms available outside the signed-in Dashboard.
---

Process Focus provides public pages for starting a process anonymously and for
completing existing work through an invitation. Neither requires a Dashboard
session.

## Anonymous process starts

An **Anonymous Page** has a stable opening address and a start button. Opening
the form requests fresh data. Back or Cancel discards the draft and returns to
the opening page. After submission, the page either returns to the start button
with confirmation or shows a completed page, depending on its configuration.

An anonymous start does not identify an external participant. A name entered
on the form is process data, not a verified identity.

## Public completion forms

A public completion form lets an invited external participant complete a Todo
in an existing process execution. The invitation is tied to its recipient.
The page explains when a link is unavailable or expired and offers a retry for
temporary loading failures.

Unlike an anonymous start, public completion attributes the submission to the
invitation recipient. An [embedded form](/docs/reference/process-steps/embedded-forms/)
also differs: it starts a process and identifies the participant through a
declared email field.
