Authorisation is deciding if an authenticated user or system can do
something. Process Focus uses [Cedar](https://www.cedarpolicy.com/)
policies to define what an identity can do, and evaluates these
policies when an identity makes a request.

Prefer policies that grant permissions to [roles](/docs/reference/authorisation/roles/)
rather than individual users.

For an introduction, see
[Authorisation concepts](/docs/concepts/authorisation/).
