---
title: To-Dos
description: Find and complete process work in the Dashboard.
---

Open **My To-Dos** in the Dashboard to find work you can complete. A
**To-Do** is a task in a particular [process execution](/docs/dashboard/process-execution/)
that needs a person to act. For example, an order might create a To-Do for
someone in the warehouse to confirm dispatch.

## Complete a To-Do

Open the To-Do, review its details, and fill in and submit the form. What
happens next depends on the process: it can create more work, run an
automated step, or finish the execution.

Use **My To-Dos** to find work you can act on. Use **Executions** to follow
the progress of the whole process run.
