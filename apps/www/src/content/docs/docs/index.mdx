Process Focus is a modern, open-source toolkit to model **Business
Process Modeling and Execution**. It provides an SDK to model business
processes in TypeScript and various runtimes to execute them locally
or in the cloud.

## What is Process Focus?

Process Focus helps you:

- **Model business processes** using a type-safe TypeScript SDK
- **Define workflows** with steps, decisions, and data transformations
- **Execute processes** locally or deploy in the Cloud
- **Manage organizations** with teams, roles, and fine-grained permissions
- **Work with your business calendar** to set SLAs so seven days are seven business days, not calendar days

## Architecture Overview

The system consists of several key components:

### SDK
The core SDK allows you to define business processes, steps, forms, and validation rules in TypeScript. Your process definitions are type-safe and can be version-controlled alongside your application code.

### Runtimes
Process Focus supports multiple execution environments:
- **Local runtime** for development and testing
- **Cloud runtime** for production deployments to the Process Focus Coud
- **Self hosting** can be by building the runtime for your own environment

### Frontend
A Next.js-based dashboard for monitoring processes, managing tasks, and interacting with forms generated from your process models.
