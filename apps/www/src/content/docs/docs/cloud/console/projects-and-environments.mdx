---
title: Projects and environments
description: Choose a project, stage, and environment in the Console.
---

A project groups its environments into stages, such as Development and
Production. Environments in the same stage share
[stage configuration](/docs/cloud/console/stage-configuration/).

Use the project picker to select your project, stage, and environment.
Open **Info** to find the environment’s site URL and the project number.
To create a project, choose **New project** and select an available region.
