---
title: Console
description: Find and manage your hosted projects in the Process Focus Console.
---

Sign in to the [Process Focus Console](https://console.processfocus.com) to
manage your hosted projects. Open an environment’s site URL to use its
Dashboard, where people start processes and complete work.

- [Projects and environments](/docs/cloud/console/projects-and-environments/):
  create a project or find an environment’s site URL.
- [Deployments](/docs/cloud/console/deployments/): check recent deploy attempts.
- [Stage configuration](/docs/cloud/console/stage-configuration/): see the
  settings shared by environments in a stage.
- [Usage and balance](/docs/cloud/console/usage-and-balance/): see environment
  costs and remaining project credit.
