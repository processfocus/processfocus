With your process defined, it's time to import it into the system and see it in action.

## Import your process

Your process is automatically imported when you start the development server. The system scans the `src/processes/` directory and registers all defined processes.

## Run your process

Start the local development server:

```bash
bun dev
```

Navigate to `http://localhost:3000` to see your process in action.
