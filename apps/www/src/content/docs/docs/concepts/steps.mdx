title: Steps
description: Understanding steps in Process Focus - the individual units of work within a process.
---

A **Step** is an individual unit of work within a process. Steps can
be manual (requiring human interaction) or automated (executed by the
system).

# Human steps

Human steps are forms: a human provides the data needed for the
subsequent part of the process.

Best practice is that human steps provide data input, not
decisions. Decisions live outside the form, in the business process
flow. For example the decision if a loan should be approved is ideally
not a human decision. The human enters the value, the process flow has
the condition if the loan can be approved: below this value, it can be
auto-approved, above this it might need human sign-off. Note that the
human sign-off is also not a decision: it would be a record of a human
agreeing, and then the system, based on the permission the human has,
continuing with the loan approval process.

# System steps

System steps are computer programs or AI agents doing some part of the
work. Examples are sending email, saving something in the database, or
ask an agent for a decision based on some input.

## Best Practices

- Keep steps atomic and focused
- Use descriptive titles and instructions
- Validate data at each step
- Handle errors gracefully in automated steps
