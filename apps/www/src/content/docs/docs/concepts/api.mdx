Process Focus is an API first system. Process Focus generates a full
[GraphQL API](https://graphql.org/learn/introduction/) from your organisation’s definition.

The Process Focus Dashboard uses the same GraphQL API that external
systems can use to start processes and work with organisation
data. For example, if your **New Order** process starts with a form
that asks for a product code and quantity, a website backend can send
those values to the generated `startNewOrder` mutation.

Staff can submit the start form in the Dashboard or via MCP. An
external system can start the same process using a [system
identity](/docs/reference/authentication/system-identities/) with a
[Cedar
policy](/docs/reference/authorisation/authorising-external-systems/)
that grants the access
