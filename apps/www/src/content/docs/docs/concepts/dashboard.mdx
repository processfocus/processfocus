Process Focus provides a web app, the **Dashboard**, where employees
can start processes, check progress or see their todos.

For example, an employee can submit an expense claim, and an approver can
open **My To-Dos** to review it. Anyone with permission to view the
execution can follow its progress in **Executions**.

The example below is the dashboard for the Demo organisation. The Demo
organisation’s **Processes** page shows which processes you can start,
with **My To-Dos** and **Executions** in the sidebar.
