# @pf/sqlite-operations

SQLite implementations of application database services, including organisation
persistence, process operations, and authentication storage.

Uses [`@pf/service-drizzle-sqlite`](../service-drizzle-sqlite/README.md) over local
or remote drivers. Shared API/runtime contracts live in
[`@pf/graphql-db-operations`](../graphql-db-operations/README.md).
