# processfocus

The source-available Process Focus authoring package for organisations,
processes, forms, authentication configuration, business calendars, frontend
manifests, and plugin declarations.

```ts
import { Organisation, Process } from "processfocus"
import { TextField } from "processfocus/forms"
```

Use `processfocus/testing` for deterministic model and Form Rule validation.
Runtime, persistence, deployment, and cloud policy are intentionally not part
of this package.
