# @pf/auth-config

Organisation-authored authentication and authorization configuration: identity
providers, passkeys, machine clients, workload trust, and custom Cedar policies.

The process model declares this configuration. Authentication and authorization
services consume it through their runtime adapters.

See [`@pf/auth-api`](../auth-api/README.md) for authentication and
[`@pf/auth-policy`](../auth-policy/README.md) for authorization.
